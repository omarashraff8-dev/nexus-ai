# NEXUS AI — المنصة الجامعية الذكية للشكاوى والخدمات

مشروع تخرج — منصة موحدة لإدارة مشكلات الطلاب والخدمات الجامعية وتحليلها بالذكاء الاصطناعي.
واجهة عربية RTL بالكامل (مع خيار English في الصفحة الرئيسية)، تصميم عصري كحلي/أزرق.

> 🌐 **نسخة حية للتجربة (GitHub Pages):** `https://omarashraff8-dev.github.io/nexus-ai/` — أدخل بحساب طالب `student@nexus.edu / student123`

---

## التشغيل (3 خطوات فقط)

المتطلبات الوحيدة: **Node.js 22.5 أو أحدث** (مثبت بالفعل على الجهاز).
لا تحتاج لتثبيت أي مكتبات خارجية — المشروع يستخدم وحدات Node المدمجة فقط (`node:sqlite`).

```powershell
cd NEXUS-AI
node server.js
```

ثم افتح المتصفح على: **http://localhost:3000**

قاعدة البيانات (`nexus.db`) تُنشأ وتُملأ تلقائيًا عند أول تشغيل: الأقسام، أنواع الشكاوى، لوائح المعهد، شكاوى تجريبية موزعة على 8 أسابيع، وحسابات تجريبية.

## المميزات المنفذة

### نظام الصلاحيات (RBAC) — بالـ Backend
- الطالب لا يرى إلا شكاواه هو فقط.
- الموظف يرى شكاوى قسمه فقط أو المسندة إليه.
- الإدارة ترى كل شيء وتديره.
- كل endpoint حساس محمي بالتحقق من الدور **في السيرفر**، وليس في الواجهة فقط.
- صفحات اللوحات لا تُفتح دون تسجيل دخول (الحارس في `common.js` + التحقق مرة أخرى في الـ API).

### لوحة الطالب
إحصائيات طلباته · تقديم شكوى (نوع + قسم + أولوية + مرفق صورة/PDF) · الاقتراح الذكي بالأزرار · متابعة الحالة · محادثة مع الموظف المختص · إشعارات عند أي تغيير · تقييم التجربة بعد الحل · مساعد ذكي يسأل عن اللوائح.

### لوحة الموظف
وارد الشكاوى مع بحث وفلاتر (الحالة/الأولوية/القسم/التواريخ) · فتح الشكوى والمرفقات · الرد على الطالب · تغيير الحالة (جديدة / قيد المراجعة / تم الحل / مرفوضة) · طلب معلومات إضافية · تحويل لقسم آخر · ملاحظات داخلية (الطالب لا يراها) · «تولّيها» للإسناد الذاتي · إحصائيات أدائه وإنجازه.

### لوحة الإدارة
إدارة حسابات الموظفين (إضافة/تعديل/حذف/إيقاف/إعادة ضبط كلمة المرور) · إدارة الأقسام وأنواع الشكاوى · كل شكاوى المعهد مع فلاتر كاملة · **إسناد الشكوى لموظف معين** · لوحة تحليلية برسوم بيانية (Canvas بدون مكتبات) · أكثر المشكلات تكرارًا · **توقع الحجم للأسبوع القادم** (انحدار خطي) · **ملخص ذكي** بضغطة زر مع حفظه · تصدير CSV (يدعم العربية في Excel) · طباعة التقرير.

### الذكاء الاصطناعي (مربوط ببيانات النظام الحقيقية)
1. **المساعد الجامعي الذكي (RAG):** بحث حقيقي داخل 10 مستندات لوائح المعهد المخزنة في قاعدة البيانات، مع استخراج أفضل جملة واستشهاد بالمصدر ورقم الصفحة. يفهم العربي والعامية (تطبيع الهمزات والتاء المربوطة والتشكيل).
2. **التصنيف التلقائي للشكاوى:** كلمات مفتاحية موزونة + كشف الاستعجال والحرج («حرمان»، «امتحاني بكرة»...) — يحدد النوع والقسم والأولوية (low/medium/high/urgent/**critical**) ودرجة الثقة.
3. **التنبؤ:** انحدار خطي على سلسلة آخر 8 أسابيع.
4. **التلخيص الذكي:** يبني تقريرًا عربيًا كاملًا من الأرقام الفعلية — بدون أي خدمة خارجية.
5. **اسأل الإدارة (AI Insights):** المدير يسأل سؤالًا بالعربي الطبيعي («ما أكثر مشكلة هذا الشهر؟») والنظام يجيب من بيانات القاعدة نفسها + رسم بياني + توصيات — بدون اختراع أي رقم.

### الميزات المتقدمة (v1.5)
- **مركز إشعارات ذكي:** جرس + عداد + قائمة منسدلة + صفحة لكل الإشعارات، إشعارات عند تغيير الحالة ورد الموظف وطلب معلومات و**اقتراب موعد انتهاء الـ SLA تلقائيًا** و**إعلان جامعي جديد**.
- **الخدمات الأكاديمية داخل حساب الطالب:** جدول المحاضرات · الامتحانات القادمة بعدّاد تنازلي · الدرجات و**المعدل GPA** · المصروفات (المدفوع/المتبقي/موعد السداد) · الحضور والغياب بالنسب · **تسجيل حضور بكود QR للمحاضرة** (الموظف ينشئ الجلسة ومدتها، والطالب يمسح بكاميرا موبايله أو يكتب الكود، مرة واحدة فقط لكل طالب).
- **تحليل المستندات بالذكاء الاصطناعي:** الطالب يرفع صورة/PDF ← النظام يستخرج النص (OCR بـ Tesseract + pdf.js) ويحدد نوع المستند (إيصال/شهادة قيد/كارنيه...) ويتحقق من اكتمال الحقول المطلوبة ويظهر حقولها الناقصة — والمحصلة تُحفظ في سجل «مستنداتي». التحليل مساعِد وليس توثيقًا رسميًا.
- **تحليل رضا الطلاب:** تقييم 1-5 ★ + تعليق للإدارة بعد حل الشكوى ← لوحة «رضا الطلاب» للإدارة (متوسط، %، مقارنة الأقسام، اتجاه شهري، أفضل/أقل قسم، آخر التعليقات).
- **المفقودات والموجودات:** إعلانات مفقود/موجود بصور وفلاتر حسب التصنيف والحالة، تواصل آمن مع المعلن عبر إشعار، حالات (مفتوح ← تم العثور عليه ← تم التسليم)، وإدارة من لوحة الموظف/الإدارة.
- **إعلانات جامعية:** المدير ينشر إعلانًا ← يظهر بانر لكل طالب/موظف + إشعار للجميع.
- **المساعد الصوتي:** الطالب يتحدث بالميكروفون (Speech-to-Text عربي/إنجليزي) والإجابات تُقرأ بصوت (Text-to-Speech) — مع زر كتم وحالة «يستمع/يعالج».
- **الأولوية الحرجة + التعديل اليدوي:** مستوى Critical مع نبض مرئي في كل اللوحات، والإدارة والموظف يقدرون يغيّروا الأولوية يدويًا من داخل الشكوى.

> ✅ لا توجد أسماء أو بيانات مخترعة في التحليلات — كل رقم محسوب من قاعدة البيانات نفسها.

## البنية التقنية

```
NEXUS-AI/
├── server.js          ← السيرفر: HTTP + API + static + حماية المرفقات
├── db.js              ← SQLite (node:sqlite): schema + seed + hashing (scrypt)
├── ai.js              ← التصنيف + RAG + التحليلات + التوقع + التلخيص
├── nexus.db           ← تُنشأ تلقائيًا عند أول تشغيل
├── uploads/           ← المرفقات (تتطلب صلاحية لعرضها)
└── public/
    ├── index.html     ← الصفحة الرئيسية (Landing)
    ├── login.html     ← تسجيل دخول موحد + إنشاء حساب طالب
    ├── student.html / staff.html / admin.html
    ├── css/nexus.css  ← نظام التصميم
    └── js/            ← landing / student / staff / admin / common
```

- **الجلسات:** cookie `HttpOnly` + token عشوائي في جدول `sessions` (صلاحية 7 أيام).
- **كلمات المرور:** `scrypt` + salt عشوائي لكل مستخدم.
- **الأمان:** فحص الصلاحية على كل مسار، `X-Frame-Options` و `nosniff`، حد 12MB للطلبات و8MB للمرفقات، أنواع ملفات محدودة (صور/PDF/Word)، حماية المرفقات (لا تُفتح إلا لصاحب الشكوى أو القسم المختص أو الإدارة)، rate limit على محاولات الدخول، تنظيف المدخلات `escapeHtml` في الواجهة.

## لو عايز تربط Gemini/OpenAI لاحقًا
كل نقاط الذكاء الاصطناعي في `ai.js` — استبدل/أكمل `answerQuestion()` بنداء API من **السيرفر فقط** (المفتاح في متغير بيئة `GEMINI_API_KEY`) وليس في كود المتصفح. البنية الحالية تعمل بدون أي مفتاح.

## اختبار يدوي مقترح (للعرض أمام اللجنة)
1. ادخل كطالب → قدّم شكوى «مش قادر أسجل المواد والامتحان قرب» → لاحظ تصنيفها تلقائيًا (عاجل + التسجيل).
2. سجّل خروج → ادخل كموظف التسجيل → هتلاقيها في الوارد → رد أو حوّلها أو اطلب معلومات.
3. ارجع للطالب → هتلاقي الرد في «شكوايّ» وإشعار بالحل → قيّم التجربة بنجوم.
4. ادخل كمدير → لوحة التحكم فيها الرسوم → «التقارير الذكية» → توليد الملخص الذكي → CSV.
